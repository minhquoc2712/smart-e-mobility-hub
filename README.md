# Smart E-Mobility Hub

Electric Mobility Coordination System
for the VNU-HCM Urban Area

## Project Overview

A software system for managing and coordinating
electric mobility resources across Mobility Hubs.

## Main Features

- Mobility Hub and vehicle management
- Parking and charging resource allocation
- Vehicle and parking reservation
- Smart charging scheduling
- Vehicle dispatching
- Incident handling
- What-if simulation
